# IoT-Based Smart Fan Control Using ESP8266 and KiwisIoT

## About the Project

The **IoT-Based Smart Fan Control Using ESP8266 and KiwisIoT** is a smart home automation project that allows users to control a fan remotely through the internet.

Using the ESP8266 microcontroller and the KiwisIoT platform, users can turn the fan ON or OFF from the KiwisIoT dashboard. The ESP8266 receives commands through Wi-Fi and controls the fan using a relay module.

This project demonstrates how KiwisIoT can be used to build smart home automation solutions, providing convenient remote fan control and IoT-based device management.
